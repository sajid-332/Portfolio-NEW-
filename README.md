# 💼 Personal Portfolio Website

A modern, responsive personal portfolio website developed using **HTML5, CSS3, and JavaScript**. This project showcases my academic background, technical skills, projects, and contact information in a clean and interactive user interface.

The portfolio was developed as the final project for the Web Engineering / Internet Programming Lab course.

This portfolio website represents my personal and professional profile. It demonstrates my frontend web development skills while presenting my education, technical expertise, software projects, and contact information.

# 🚀 Installation Guide

## Clone the Repository

```bash
git clone https://github.com/sajid-332/Portfolio.git
```

## Enter the Project Folder

```bash
cd Portfolio
```

## Open the Website

Simply open

```
index.html
```

in your preferred browser.

You may also use the **Live Server** extension in Visual Studio Code.
